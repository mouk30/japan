## 표기 및 한계

- 사진의 원본 페이지를 현장에서 열어 촬영 대상 및 명시적 사용 라이선스를 검토했다. 모든 게시글의 대표 사진 아래에 촬영자, 원본 페이지, 라이선스 링크를 표시했다.
- 목판화 사진은 **에도도쿄박물관의 제작 과정 전시 사진**이지 장인의 실제 인쇄 작업 현장 사진이 아니다.
- 하코네 사진은 **스위치백 선로·신호장 실제 사진**으로, 열차가 함께 찍힌 것은 아니다.
- 아리타 사진은 **포슬린 파크에 있는 가마**이며 실제로 가동 중인 가마라는 주장은 하지 않는다.
- 화면 비율에 맞춰 CSS에서 이미지 가장자리가 일부 잘릴 수 있다. 해당 사실은 각 게시글의 사진 출처에 표기했다.
- 공개된 라이선스는 각 원본 파일 설명 페이지를 기준으로 한다. CC BY-SA 작품의 변환 WebP 파일에도 사진 원본별 동일 라이선스가 적용된다. 다른 사이트 콘텐츠에 라이선스가 전이된다는 뜻은 아니다.
- 최초 GitHub 반영에서는 원본 호스팅 URL을 사용한다. `scripts/v34_cache_images.py`와 `.github/workflows/v34-cache-images.yml`에서 5종을 WebP로 저장하고 본문/OG URL을 내부 경로로 변경하도록 구성한다. **실제 캐시 성공 여부는 GitHub Actions 실행과 결과 커밋을 별도로 확인해야 한다.**
- 교토 대나무숲 `japan-bamboo-grove-ecology`는 이미 실사 이미지가 연결되어 있어 변경하지 않았다. 쓰바메산조 금속 공예 글은 촬영 대상을 확인할 수 있는 적절한 무료 사진을 확보하기 전까지 기존 상태를 유지한다.
