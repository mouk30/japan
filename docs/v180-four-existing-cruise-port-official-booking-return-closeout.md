### 1. 히메지

- [시라사기 공식 디지털 티켓](https://himejicastle-ticket.jp/)과 [히메지성 공식 관광객 쿠폰권](https://himeji-kanko.book.ntmg.jp/) 실제 구매 화면 추적. **1,000엔 시내 쿠폰 교환권 동봉 상품은 2026년 10월 31일 입장분까지**. 11월 1일 이후에는 기본 시라사기 사이트 구매로 전환. 1,000엔 쿠폰은 전자권을 종이 쿠폰으로 교환해야 매장에서 사용 가능; 교환하면 티켓 취소·방문시간 변경 불가. 쿠폰 상품이 없는 일반 시라사기 티켓은 해당 특전 대상이 아님.
- [히메지시 2026년 8월 디지털권 안내](https://www.city.himeji.lg.jp/castle/0000030310.html), [히메지성 공식 요금](https://himejicastle.jp/): 일반 성인 2,500엔, 히메지성·고코엔 공동 2,600엔, 18세 미만 무료. 방문시간 30분당 500장·1회 10장 제한, 30명 이상 단체 할인은 웹티켓 적용 불가. 미사용·유효기간 내 취소 가능, QR 입장 처리 후에는 취소 불가. 운영시간 09:00~17:00, **마지막 입장 16:00**.
- [히메지항 공식 2026 크루즈 입항](https://himeji-port.com/enterportplan): 11월 25일 아스카Ⅲ 08:00~21:00 예정, 시간/선석/취소 변경 가능. 시내 성·역의 관광 마무리와 본선의 실제 승객 귀선 게이트는 다름. 출항 21:00은 마지막 승객 승선 마감이 아님.

### 2. 도코나메

- 공익 실버인재센터 [도자기길 해설 RESERVA 실제 승인형 예약](https://reserva.be/potteryguide): 90분 팀 프로그램, 1~5명 1,500엔/6명 이상 3,000엔. 전화·메일 수신은 예약 접수가 아니며 온라인 신청 승인 확인 필요.
- [해설운영 기관 원문](https://tokoname.wixsite.com/potterypath): 전체 1.6km, 집합 도코나메 도자기회관 동쪽, **실시 5일 전 예약 마감**. 7월 20일~8월 31일, 12월 28일~1월 8일 휴업. **취소 3일 전 무료, 2일~전날 50%, 당일 100%**. [아이치현 공식 관광](https://www.aichinow.pref.aichi.jp/spots/detail/33/): 도자기 산책로 자체는 **무료**이므로 해설권을 마을 입장권으로 표현하지 않음.
- [국토교통성 도코나메 기항 부두](https://www.mlit.go.jp/kankocho/cruise/detail/120/index.html): **센트레아 부두 vs 고이에신카이 부두** 구분. 공항역에서 센트레아 부두까지 도보 5분이라는 자료는 다른 부두의 크루즈 귀선거리나 시간 보증이 아님.
