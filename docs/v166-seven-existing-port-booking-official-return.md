## 적용 원칙
- 각 기존 `index.html` <article> 상단에 공식 운항/변경, 정식 예약/취소, 항만별 실제 마지막 귀선의 3개 큰 정보카드. 모바일 1열·CTA 최소 52px.
- 위 출처의 **임시 시스템 점검/예정** 정보는 해당 일자에만 묶어 설명. 반드시 여행 당일 사업자 발표 재확인.
- **기존 SEO/원본 WebP/촬영·CC/URL/sitemap/내부링크는 보존.** 대표 이미지 7장/캡션을 새로 제작/교체하지 않음.
- 두 기간·항차가 다른 정기 페리와 대형 크루즈를 혼동하지 않음. 진짜 예약 잔여석, 결제 성공, 크루즈 최종 귀선시각, GA4/GSC는 확인하지 않음.
