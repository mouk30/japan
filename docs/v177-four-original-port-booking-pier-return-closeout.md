## 운영기관 공식 대조

### 1. 무로란
- [스타마린 직접 예약 신청서](https://star-marine.co.jp/reserve.html): 야경/항내/지구곶/돌고래 관광선 등 실제 선택 가능한 신청서. [사전 예약 조건](https://star-marine.co.jp/prior_confirmation.html): 웹 예약 3일 전까지, 전날·당일 전화 0143-27-2870. 온라인 작성=결제/예약 확정 아님.
- [현장 승선 장소·접수 마감](https://star-marine.co.jp/cruise/access.html): 출항 20분 전 현장 도착, 1시간 전부터 접수. 스타마린 관광선 승선장 슈쿠쓰초 4-16-15(미타라무로란 인근).
- [무로란시 2026-10-13 공식 크루즈 공지](https://www.city.muroran.lg.jp/content/?content=5662): 네비게이터 오브 더 시즈 10/15 슈쿠쓰부두, 세븐시즈 익스플로러 10/16 중앙부두. 이는 과거 날짜별 선석 예시이지 모든 크루즈의 고정 선석이 아님. 부두 보안 차량 진입 제한 및 다른 선석 최종 귀선.

### 2. 모지코
- [모지코 레트로 공식 패스 판매 목록](https://mojiko-retoro9.jp/ticket/)에서 [실제 Webket 구매 링크](https://webket.jp/pc/ticket/index?ac=9000&fc=80054)를 찾아 기존 항만 정보 포털 대신 연결. 성인 1,700엔·초중학생 720엔 통합권, 당일 한정. 웹 자동 크롤러는 Webket 403 응답을 받을 수 있으므로 실제 브라우저 접속 환경/판매상태는 결제 직전에 확인, 판매처 확인에 실패하면 운영사 공식 목록 페이지로 돌아가야 함.
- 운영사 통합권과 트윈타워권(구매 후 3개월)·관문유유권(구매 후 7일) 구분. 일부는 시설 창구 발권으로 모든 표가 동일한 온라인 결제수단이라고 표시하지 않음.
- [관문기선 가라토↔모지코 실제 왕복시간표](https://www.kanmon-kisen.co.jp/route/kanmon.html): 통상 5분, 성인 편도 400엔·소아 200엔. [기타큐슈시 공식 크루즈 선석 4곳](https://www.city.kitakyushu.lg.jp/contents/30400002.html) — 모지 서해안1·2호, 서해안6호, 고쿠라 아사노1호, 와카마쓰 히비키 CT; 총 '4개 구역/유형'으로 시 표기, 여러 안벽 포함. 모지코 관광선 마린게이트 모지에 도착했다 해도 히비키 CT 등 본선 원래 크루즈 게이트까지 별도 귀선차량 필요.

### 3. 사카타
- [혼마미술관 공식 요금/영업시간](https://www.homma-museum.or.jp/use/): 일반 1,300엔, 고교·대학생 600엔, 초·중학생 무료, 구 혼마 본저택과 공동권 2,000엔. 4~10월 09:00~17:00 마지막 16:30, 11~3월 09:00~16:30 마지막16:00. 실제 판매 화면이 아닌 현장 관람/요금 안내임을 명시.
- [사카타시 산쿄소코 공식 무료 관람](https://www.city.sakata.lg.jp/bunka/bunkazai/bunkazaishisetsu/sankyosouko.html): 외관 상시, 안내센터 09:00~16:30, 12/29~1/3 휴관, 무료. [시영 룬룬버스 2026-04-01 개정 시간표](https://www.city.sakata.lg.jp/sangyo/kotsu/runrunbas/R070401citybus.html)는 관광객 교통이며 외항 크루즈선 무료 전용 셔틀이 아님.
- [사카타시 기항 예정과 북항 고미나토부두](https://www.city.sakata.lg.jp/sangyo/kotsu/kouwan/shoko0320191023.html): 일반 예정선석 북항 고미나토, 9/3 예시는 다카사고부두로 변경된 사례. 실제 항차 귀선지는 선사 항차별로 재확인해야 하며 시내 역/버스 정류장 ≠ 북항 선사 승객 보안 게이트.

### 4. 센다이
- [우미노모리 수족관 공식 Web입장권 안내](https://www.uminomori.jp/umino/webket/index.html)가 가리키는 [아소뷰 구매 채널](https://www.asoview.com/channel/tickets/CfQ553fPJ6/) 직접 연결. 성인 2,400엔·중고생 1,700엔·초등생 1,200엔·유아(4세~) 700엔·시니어(65세~) 1,800엔, 입장 최소 15분 전 구매, 구매 후 6개월 이내 사용. 장애인 등 할인권은 현장 창구, 일부 옵션 프로그램은 현장 접수여서 구분.
- [우미노모리 수족관 2026 가을·겨울 운영시간](https://www.uminomori.jp/umino/info/): 9/28~11/3 09:00~17:30(마지막17:00), 11/4~3/19 10:00~17:00(마지막16:30).
- [미야코버스 수족관→JR 나카노사카에 역 실제 귀선 검색](https://transfer.navitime.biz/miyagikotsu/pc/transfer/DepArrTimeList?gnode=00330517&snode=00332351)과 [수족관 현장 교통 안내](https://www.seaparadise.co.jp/en/umino/access/): 성인 편도 200엔, 정규 공개 기준 막편 16:00; 계절별 증편·감편 가능, 크루즈 승객 게이트까지는 별도의 버스·택시 필요.
- [미야기현 대형 크루즈 입출항 기준](https://www.pref.miyagi.jp/soshiki/kouwan/cruise-koukouanzenyouryou.html): 센다이시오가마항 센다이항구의 외항 크루즈선은 수족관 관광지/정기페리 여객 승선장과 독립된 귀선 조건.
