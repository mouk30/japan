## 범위와 실적

- 대상: 기존 대표 이미지 40편 + 주제 참고 이미지 12편, 합계 **52편**. 신규 게시글 0편, 기존 URL 변경 0건.
- 모두 실제 파일 존재 및 WebP 열기 가능: **52/52**.
- 목록의 사진과 기사 대표 이미지 경로 일치: **52/52**.
- V42 적용 전 OG 매칭 50/52, Twitter 이미지 매칭 5/52 → **적용 후 OG·Twitter 52/52**.
- 대조용 이미지 접촉표를 만들어 52개 썸네일의 내용과 제목을 직접 비교함. 파일명만 같다는 이유로 실제 촬영물이라고 간주하지 않음.
- 관련 참고 이미지 12편 중 **11편을 실제 촬영 사진과 공개 라이선스 출처로 교체**. 기모노/유카타 비교 이미지 1편은 편집 비교 이미지로 명시하고 유지.
- 종전 40편 중 **20편은 게시글에서 기존 사진 원본·라이선스 링크를 확인**, 다른 20편은 독립적 원본 증빙을 확인하지 못해 편집 이미지로 분류. *원본 출처 링크가 있다는 사실과 사진의 현장 진위 전체를 독립 검증했다는 사실은 같지 않음.*
- 실사 사진 교체 후 실제 프리뷰를 추가 비교하여 에키벤 사진을 도시락 진열 실제 사진으로, 긴쓰기 사진을 박물관의 금칠 수선선이 더 명확한 도자기 유물로 수정.
- 사진 출처 문구가 이미지 오류 처리 속성 내부에 삽입된 HTML 구조 문제 **3건 수정** (에키벤·긴쓰기·오미야게).
- **실제 Vercel 배포 성공 + 운영 사이트 105/105 통과**. WebP 52건은 HTTP 200/RIFF 서명뿐 아니라 **실제 응답 SHA-256가 최신 GitHub 로컬 파일과 같음**을 확인; 기존 글 52건은 이미지, OG, Twitter가 실제 주소와 일치했고, 목록 허브 1건도 20x? 아닌 52개 이미지 링크 포함 확인.
- 모바일/PC 브라우저 실화면의 크롭·카드 높이까지 자동 스크린샷으로 검증한 것은 아님.
