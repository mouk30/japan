# V146 — 세토내해 예술섬 검증·발행 기준

정보 최종 확인: 2026-10-23 / 관리 대상: 나오시마·데시마 각 1편. 신규 페이지 대량 확장 보류.

## 품질 게이트 (4단계: 반드시 모두 검증)
1. **배편 확인** — 출발 항구와 귀항 항구를 *정확한 일본어 항구명*으로 구분하고, 운항사·배 종류·요일·계절·당일 기상 운항상황까지 해당 운영사 공식 페이지에 연결한다. 선착순 승선은 좌석 확보가 아님을 적는다.
2. **미술관 예약** — 운영자가 제공하는 공식 예약/티켓 페이지, 방문일·시간 지정 조건, 휴관일, 예약 매진 시 당일 발권 가능 여부를 분리한다. 공연·특별프로그램은 일반 관람과 혼동하지 않는다.
3. **현지 이동** — 하선 → 정류장 → 환승 → 시설 입구 → 역방향 복귀를 분리한다. 버스의 정원·요금·현금 가능 여부 및 승선/버스 시간 미연결 주의 사항을 명확히 한다.
4. **안전한 귀항** — 돌아갈 항구와 배 출항 시각을 역산하여 교통편을 정하고, 기상·버스 만석·미술관 지연 시 관광 포기 대안을 준다. 크루즈 본선의 승객 최종 귀선 마감은 연안 여객선 출항시각과 별도로 계산한다.
