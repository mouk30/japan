## 증거 수준 (섞어 보고 금지)

1. **기술 노출 준비**: 3개 URL의 HTTP 200, canonical, noindex 부재, 사이트맵, 링크 스크립트 응답. `scripts/check_longtail_3_readiness.py --mode live`로 확인. 이 결과는 검색 노출 자체가 아니다.
2. **검색 노출**: Google Search Console과 네이버 서치어드바이저에서 URL별 노출수·클릭수·검색어·기간. 양 서비스 값은 서로 다르므로 출처 구분.
3. **실제 방문**: GA4 유기적 방문 세션 및 방문 경로. GA4 측정 ID·동의 설정·디버그 테스트가 확인되지 않았으면 **미측정**으로 표기.
4. **예약 시작**: `nf_travel_link_click` 이벤트 중 `link_type = operator_booking_start`. 현재 확실히 직접 예약 진입으로 분류한 경로는 뉴카멜리아 한국어 예약 달력이다. 타사 안내 홈페이지 이동은 `operator_official_info`이며 예약 시작으로 세지 않는다.
5. **예약 확정·매출**: 운영사/제휴사의 실질적인 전환·매출 근거 없으면 **미확인**. 링크 클릭 수를 예약 건수로 대체하지 않는다.

## 측정 연결이 아직 필요한 항목

- **Google Search Console**: 이 도메인의 세 상세 URL에 대한 노출·클릭·CTR 데이터를 계정에서 조회해야 한다.
- **네이버 서치어드바이저**: URL별 실제 웹문서 검색성과를 계정에서 확인해야 한다. 노출 위치별 차이는 도구 제공 범위에 따라 다르다.
- **GA4/GTM**: 3개 페이지에 클릭 이벤트 코드 `/nf-longtail-clicks.js`가 있어도 GA4 태그 또는 GTM이 설정되지 않으면 지속적으로 수집되지 않는다. 측정 ID를 추측해 넣거나 동의 없이 개인 정보를 수집하지 않는다.
- **실제 예약**: 제휴 트래킹 또는 운영사 발급 실적이 있어야 한다.

## 의사결정 기준

- 기술 검사 실패 → **노출 성과 해석을 중단하고 기술 문제부터 해결**.
- 색인되지 않음 → 색인 요청·canonical·중복·콘텐츠 품질 점검.
- 노출은 있으나 클릭이 적음 → 제목·설명과 실제 검색 의도 점검.
- 클릭은 있으나 예약 행동이 없음 → 공식 가격/조건/예약 경로의 정보 밀도 점검.
- 노출·클릭·예약 행동이 꾸준히 확인되는 주제 → 해당 검색 의도와 다른, 새로운 문제를 해결하는 글만 **소규모 실험**.
- 통계적으로 불충분한 표본에서 특정 주제가 '승리'했다고 단정하지 않음.

**주의:** GitHub Actions의 매일 검사는 공개 URL의 기술 상태를 확인하는 것이지 서치콘솔을 읽거나 예약수를 생성하는 기능이 아니다.


## V3 · 실제 검색 CSV 기반 비교 (전환 자료 없이 진행)

기존 3개 페이지만 비교합니다. **예시 숫자를 실제 성과처럼 게시하지 않습니다.**

Google Search Console에서 같은 날짜 범위를 선택하고 **검색결과 실적 > 페이지별 결과 > 내보내기(CSV)**를 실행한 후, URL·클릭·노출 열이 들어 있는 페이지별 CSV만 사용합니다. 검색어(queries)만 들어 있는 파일은 잘못된 비교를 막기 위해 거부합니다.

```bash
python3 scripts/report_longtail_3_search.py \
  --gsc-pages "/path/to/Pages.csv" \
  --start 2026-10-19 --end 2026-11-15
```

네이버 서치어드바이저에서 **URL·클릭·노출이 함께 있는 페이지별 CSV**를 얻을 수 있는 경우에만 `--naver-pages "/path/to/naver.csv"`를 추가합니다. 네이버의 검색어별 자료를 URL별 데이터로 착각해 결합하지 않습니다. 프로그램은 `audit-output/longtail-3/search-evidence/summary.json`과 `summary.md`를 생성합니다.

**미측정 ≠ 0:** CSV가 제공되지 않았거나 해당 URL이 내보낸 자료에 없으면 `not_provided` 또는 `not_in_export`로 표시됩니다. 실제로 측정된 클릭 0만 0으로 표시합니다. 검색엔진별 표는 따로 보존하며 방문 세션·예약 확정이나 매출을 추정하지 않습니다.

**데이터 보호:** 서치콘솔 원본 CSV나 실측 내역은 공개 GitHub 저장소에 업로드하지 않습니다. 로컬에서 보고서를 만든 후 필요한 합계만 공유하며 민감한 계정·개인 정보는 제외합니다.

**평가 시점:** 배포일부터 최소 28일 이후 가용 데이터를 비교하되, 노출·클릭이 부족하면 결론을 유보합니다. 신규 키워드 페이지는 성과가 입증되기 전까지 추가 생성하지 않습니다.
