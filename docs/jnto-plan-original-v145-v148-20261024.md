## 가장 중요한 정보 구분
- **예약**: 미술관 날짜·시간 지정권, 입욕 객실 예약 등은 운영기관 원문을 연결. 일반 입장·일반 식사는 예약 상품처럼 표시하지 않음
- **현지 이동**: 승객 크루즈 선석과 일반 페리터미널을 구분. 버스·차량 편수와 소요시간은 실제 항차·방문일에 재확인
- **귀선**: 마지막 관광지 출발 시간 → 복귀 교통 → 원래 승객 게이트 → 선사 최종 탑승 마감 순으로 역산. 임의 시간표·빈자리 수치를 제공하지 않음
- **사진**: 검증된 기존 실제 장소 WebP 및 원저작자·CC 라이선스·변환 기록을 유지. 신규 미식 시범은 기존 `japan-kagawa-udon-pilgrimage.webp`로 가가와현 우동만 보여줌(타 도시 사진으로 오인 금지)
