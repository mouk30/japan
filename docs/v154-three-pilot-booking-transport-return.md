# V154 — 기존 시범 3편 예약·현지교통·귀선 최우선 정보보강
기준: 2026-10-24. 신규 글 0편. 기존 URL·SEO·대표 실사·사진 저작자·CC 허락 유지.

## 사용자 행동에 바로 연결되는 확인 사항
1. **나오시마 미술섬**: 지추미술관 날짜·시간권 결제는 선박·마을버스 예약이 아님. [Benesse FAQ](https://benesse-artsite.jp/en/faq/chichu_art_museumonline_tickets.html)에는 온라인 카드 결제, 구매 후 개인 사유의 일정 변경/취소 제한, 대중교통 좌석 비보장 등이 안내됨. 미야노우라항 → 쓰쓰지소 마을버스 → 지추미술관 무료 셔틀 동선을 [Benesse 접근 안내](https://www.benesse-artsite.jp/en/access/naoshima/)에서 확인. 우노·다카마쓰 승선항과 선종별 부두 차이는 [시코쿠기센](https://shikokukisen.com/en-routes/)에서 확인.
2. **데시마 예술섬**: 이에우라항·가라토항은 별개의 여객선 접안 항구. 미술관 입장권은 별도 날짜·시간 예약 대상이지만 페리 좌석 보장이 아님. [데시마 관광협회](https://teshima-navi.jp/en/access/)는 일부 여객선 현금 결제, 선편별 정리권과 섬내 버스 대인요금 400엔을 안내하나, 방문일 시간표·요금은 재확인 필요. [공식 선사](https://www.shodoshima-ferry.co.jp/timetable/) 운항 및 정차항 확인 후 돌아오는 버스를 역산.
3. **시코쿠 기항지 미식**: 다카마쓰·도쿠시마·고치는 각각 별도의 크루즈 기항지로, 한 도시에 모두 위치하지 않음. [사누키 마르셰 2026 공식 일정](https://www.kensanpin.org/marche/schedule/)에서 10월 18일/10월 25일(연기일), 11월 15일/11월 22일(연기일), 7·8·12월 휴장 표시를 확인. 연기일은 행사 확정일이 아니며, 점포·관광명소 운영과 구분.

## 공통 흐름
**검색 진입 → 정확한 출발·하선 항구 → 별도 시설 예약/공식 운항 확인 → 섬·도시 내 교통 → 승객 게이트 최종 귀선 시각 역산** 순서로 페이지 상단의 큰 3단계 카드와 공식 링크를 제공함.

- 서식: 3단 데스크톱·모바일 1단 카드. 44px 이상 링크/CTA. 실제 예약 재고·최종 셔틀/선박 탑승시각을 가정하지 않음.
- 추적: V152/V153 동의 기반 `nf_pilot_action_click`의 기존 허용값 `museum_info`, `island_transport`, `ferry_schedule`, `official_food`, `port_return`, `return_plan`만 재사용. 신규 개인정보나 실제 완료/결제 전환 이벤트는 발송하지 않음.
- 품질: 기존 콘텐츠의 canonical·H1·메타설명·대표사진 위치/ALT 및 저작자·CC 라이선스와 모든 기존 링크를 보존. Naoshima/Teshima Article JSON-LD 수정일은 2026-10-24로 갱신.
- GA4 연결 상태: 이전 실제 사이트 확인상 `GA4_MEASUREMENT_ID`가 없으므로 **실측 이벤트 수집 미시작**. Google/Naver Search Console, GA4 데이터를 연결하기 전에는 조회·클릭·매출을 0으로 기록하지 말 것.

## 운영 변경 유의
이 문서의 금액·취소·행사 일정은 지정한 공식 페이지의 2026-10-24 확인 내용이지 예약·운항 가능 현황을 보장하지 않음. 풍랑/휴관/연기/셔틀 변경은 **출발일 공식 공지**가 최종 기준이다. 기존 페이지 증산 없이 실전 정보를 보강한 단계이므로 28일 뒤 검색 성과가 확인되기 전 신규 테마 확장 없음.
