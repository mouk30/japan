## 판별 기준 및 표기 정책

- 쓰바메산조 사진은 **실제 니가타 산조에서 만들어진 제품 사진**이다. 공방 거리 자체, 수작업 장면이나 전시장에서 작업 중인 인물을 촬영한 사진이라고 주장하지 않는다.
- 하카타오리 사진은 **전시된 직기**의 실제 촬영본이다. 현재 생산되는 공방이나 장인의 작업 현장으로 오인하지 않도록 설명한다.
- 빈가타 사진은 **19세기 직물 유물**이고 현대 공방의 염색 시연 사진이 아니다.
- 구미코·스다레는 실제 공예 결과물 또는 설치물을 촬영한 사진이다. 공예 공정을 직접 기록한 사진이라고 말하지 않는다.
- 5편의 실제 실사 원본 URL과 촬영자·라이선스 링크를 대표 사진 아래 가시적인 문장으로 제공한다. CC BY-SA 사진을 WebP로 변환하고 축소함을 명시하며 CC BY-SA 4.0를 표시한다.
- 본문 텍스트와 canonical URL, 내부 링크, 기존 sitemap 항목은 유지한다. SNS 공유 이미지는 실사 WebP와 동일하게 맞춘다.
- 파생 WebP 이미지는 `site/images/culture-verified/<slug>.webp`. 파생 사진은 개별 원본 저작물의 라이선스를 준수한다.
- 자동 작업: `scripts/v35_cache_images.py`와 `.github/workflows/v35-cache-images.yml`. 외부 사진 5건 모두 내려받아 파일이 올바른 이미지인지 확인한 다음에만 게시글을 수정하도록 구성했다.
- 실제 Actions 결과, GitHub 이미지 파일 존재 및 Vercel 배포는 별도 점검해 완료 여부를 판정한다. 전체 사이트 화면 QA는 별도 검사 없이는 성공으로 적지 않는다.
