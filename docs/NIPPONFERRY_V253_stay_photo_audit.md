# NIPPONFERRY V253 — 숙박 카드 사진·지역·원본 픽셀·ALT 검수

검토일: 2026-10-30. 검토 기준: **지역명이 사진의 실제 촬영 장소를 증명하지 않으며, 큰 이미지 파일도 실사·이용허가 증거가 아닙니다.**

## 정적 검수 범위

- 기존 숙박 가이드 `/stay/` 및 27개 하위 페이지 = **28개 페이지**.
- 기존 공용 JPEG 파일명 **9종**. `fuji.jpg`·`hakone.jpg`·`ryokan.jpg`는 파일 SHA가 같은 **동일한 사진 3개 이름**. 실제 중복 콘텐츠 제거·권리 소명 필요.
- 가고시마(사쿠라지마)·오키나와 페이지에 후지산 배경, 나고야·센다이·요코하마 페이지에 도쿄타워 배경, 히로시마 페이지에 교토 이미지 등이 사용되는 **지역과 이미지 불일치·출처 미검증** 문제 확인.
- 기존 JPEG 9개는 CI에서 실제 바이트를 열어 픽셀 크기와 SHA를 계산합니다. 이 도구 밖에서 1MB 이상 이미지 API 조회가 비어 있었던 것을 이미지 손상으로 해석하지 않습니다. **픽셀 크기와 사진 촬영 장소/실사 여부를 구분**합니다.

## 실제 변경

- 기존 28개 숙박 가이드에서 지역·숙소 현장 이미지라고 오해할 수 있는 이미지 ALT를 **사진에 보이는 내용과 미검증 상태를 반영한 참고 이미지 설명**으로 수정.
- 사진을 실제 시설의 사진으로 사용한다는 오해를 줄이도록, 각 가이드 상단에 출처·실제 시설 확인 전 상태를 명확하게 표시. 카드 레이아웃, URL, title, canonical, robots, 내부 링크는 유지.
- 홋카이도 `노보리베쓰` 카드의 **잘못 복제된 후지산/하코네 이미지**를 기존 사이트에 이미 보유한 실물 촬영 사진으로 교체. 원본: `Noboribetsu Onsen hot spring.jpg`, Lawsonstu, 2015-04-07, CC0 1.0, Wikimedia Commons. **실제 온천 지형이며 숙소 객실 사진이 아님**을 명시하고 원본/라이선스를 링크함.
- 허가·촬영지·시설이 불확실한 다른 사진은 임의로 새 실사로 승인하거나 다른 도시 사진으로 위장해 교체하지 않음.
- 새 글: 0개. KidsStay 원본·시범 프로젝트 및 예약경로: 변경 없음.
