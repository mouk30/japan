# V107 — 메인 지역별 즐길거리 실장소 이미지 정합성 개선

**2026-10-22 · 대상: https://www.nipponferry.com/의 `도착해서 뭐 하지? 지역별 즐길거리` 4개 카드 중 3개**

## 적용 내용

| 지역 카드 | 이전 이미지와 문제 | 새로 연결한 기존 WebP | 확인된 화면상의 주제 |
| --- | --- | --- | --- |
| 오사카 | 타코야키 클로즈업만으로 도시 체험 카드 구분이 어려움 | `/images/venues/osaka-kaiyukan-aquarium.webp` | 오사카 덴포잔의 가이유칸 수족관 건물과 항만 |
| 시모노세키 | 바다 건너 모지코가 카드의 중심으로 노출 | `/images/venues/v62-karato-market-real.webp` | 시모노세키 가라토시장 건물·수변 |
| 대마도 | 일반 음식 이미지가 히타카츠/이즈하라 도착항 안내와 불일치 | `/images/venues/v62-izuhara-port-real.webp` | 이즈하라항 국제터미널과 선착장 |

- 각 이미지는 이번 버전에서 외부에서 가져오거나 AI로 새로 만든 것이 아니라 **이미 저장소에 있던 WebP**를 메인 카드에 재활용했다.
- 가라토시장 및 이즈하라항 자료 사진은 기존 상세 가이드의 OG 대표 이미지와 동일하다. 카드의 목적지 혼동을 줄였다.
- 기존 오사카·시모노세키·대마도 카드의 `href`, 제목, 설명, 배치와 700×460 이미지 선언을 유지했다.
- 실제 장소 자료 사진에 잘못 붙는 **‘여행 분위기 연출 이미지’** 표시는 제거했고, 후쿠오카 연출 표시만 유지했다.
- 하단 안내문에 이즈하라/히타카츠 구분과 시모노세키/모지코 구분을 명시했다.
- 기존 홈페이지 canonical, JSON-LD, 카테고리별 8/4/6 카드 개수, 이미지 종횡비, lazy loading, 썸네일 관련 CSS, 기존 SEO와 사이트맵은 그대로 유지한다.

- `scripts/v104_home_thumbnail_browser_qa.py`: PC 1440px / 모바일 390px / 소형 360px에서 실제 18개 이미지와 V107 카드 alt가 일치하는지 재검증하도록 업데이트.
- `tests/test_v105_home_photo_quality.py`: 기존 사진 18개 무결성 검사와 더불어 V107 3개 카드, 가라토시장·이즈하라항 상세페이지 OG 이미지 연결을 검증.
- 요약 보고서의 연출/참조 사진 수치를 고정값이 아닌 실제 검사값으로 표시하도록 수정.
