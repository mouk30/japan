# V112 — 세 번째 10편 기존 상세페이지 실사 출처·촬영시점·SEO 보강

**작업일: 2026-10-22 · NIPPONFERRY · 신규 게시글 0편 · 수정된 기존 페이지 10편**

## 변경 판단
V110·V111에서 이미 다룬 지역을 제외하고, 원본 촬영 시점의 차이가 현재 여행자에게 오해를 줄 수 있는 오타루·도쿄·아키타·마이즈루·히로시마·이와쿠니·구레·모지코·아부라쓰·사카이미나토 총 10편을 검수했다.

**이 10편은 기존 WebP 사진이 실제 지역 관광지 및 출처와 맞아서 사진 교체가 필요하지 않았다.** 새 글과 새 이미지를 늘리지 않고, **대표 사진 10개 모두의 촬영 시점·장소·저작자·라이선스·현재 운영정보와 구분**을 강화했다.

## 실시한 수정

- **사진 파일 교체 0건**: 검증된 실제 장소 WebP 10개를 그대로 사용하여 원본 바이너리와 URL 보존.
- **촬영 날짜·시설 정체성·라이선스 문구 10편 교정**: 각각 사진 바로 아래에 일관된 출처 크레딧, 촬영 시점, 관광지와 승선부두의 차이를 명확하게 표시.
- **오타루·도쿄 2편 일반 페리 이미지 자동 대체 동작 제거**: 사진 로딩 실패 시 다른 지역 페리 이미지가 원래 사진처럼 대체되는 문제를 방지.
- OG 대표 이미지 10개는 이미 본문 실사와 일치하여 **추가 교체 없이 유지**.
- 촬영이 2007·2009·2014년 등 오래되었더라도 관광 시설의 현재 운영시간, 가격, 리모델링, 하선 게이트를 보증하지 않음을 표시.
- 기존 `title`, `meta description`, `H1`, `canonical`, 원래 `JSON-LD`, 페이지 URL·본문 여행 동선 유지.

## 제한 사항
- 사진은 촬영 당시의 장소 모습이다. 2026년 현재 시설/운항/예약 상황이 동일하다는 증거로 사용하지 않는다.
- Flickr 또는 Wikimedia Commons 원본 기록과 기존 편집 출처를 기준으로 검수하였으나, JPEG→WebP 변환의 전체 처리 이력을 각각 독립 재현한 것은 아니다.
- 검수 대상은 선택한 **10개 기존 상세페이지**뿐이며 전체 사이트 사진 100% 검증 주장이 아니다.
- GA4에 연결하지 않았으므로 실제 트래픽 순위에 따른 선정은 아니다.
