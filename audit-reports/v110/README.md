## 실제 변경
- **4편**의 화면에 보이는 대표 이미지를 교체.
- **10편**의 `og:image`를 각 페이지의 실제 출처 확인 사진과 일치시킴.
- **10편**의 사진 alt에 구체적인 지역명·실제 관광시설과 '크루즈 접안 부두가 아님' 또는 '현재 접안 게이트를 보증하지 않음' 등을 명시.
- **10편**의 캡션에 원본 사진 URL, 저작자, 라이선스, WebP 파일 변환 안내를 직접 노출.
- 이미 저장소에 있던 WebP 파일만 사용하여 다운로드·신규 이미지 생성 없음.
- 원본 URL, 제목, 검색 설명, H1, 구조화 데이터 및 상세 관광 가이드는 유지.

## 사실성·저작권 한계
- 관광시설 사진은 그 시설의 촬영 시점 기록이다. **실제 크루즈 승객 게이트·접안 부두·셔틀·운항/예약 상태를 증명하지 않는다.**
- Wikimedia Commons 원본/라이선스 정보와 과거 내부 V80·V62·V10 추적 자료를 사용했으며, 모든 원본 제작 권리의 독립적인 법적 보증은 아니다.
- 원본에서 재사용 WebP로 이어지는 변환 과정까지 모든 사진에 대해 독립 재현한 것은 아니다.
- 이번 대상은 **이 10편**이며 기존 145개 기항지 및 사이트 모든 이미지가 검증됐다는 주장은 하지 않는다.
- 특정 페이지가 검색 트래픽 최상위라는 근거는 GA4 연결 전이므로 사용하지 않았다.
