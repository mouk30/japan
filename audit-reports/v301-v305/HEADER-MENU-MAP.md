## V303 — 모바일
- 최대 1199px: 메인/보조 데스크톱 메뉴 대신 로고·예약 CTA·햄버거 버튼을 보여준다.
- 펼침 상태를 `aria-expanded`로 표시하고, 열리는 메뉴는 `inert` 속성을 해제한다.
- 키보드 Escape로 닫기, 외부 클릭시 닫기, 기존 본문을 덮지 않는 스크롤형 오버레이를 지원한다.
- 하위 지역: **도쿄 220편**, 오사카, 후쿠오카, 오키나와, 홋카이도, 고베, 대마도, 시모노세키.

## V304 — PC 드롭다운
- 일본 여행지·즐길거리·동행 가이드·여행 정보 4종은 마우스오버와 버튼 클릭을 지원한다.
- 메인 글씨는 탭, 메가메뉴는 해당 지역·시설로 진입하는 링크. 키보드 탭·Escape 지원.
- 클릭할 수 없는 장식 버튼은 사용하지 않는다.

## V305 — 홈과 전 사이트 통일
- 기존 첫 화면의 11개 밀집 이모지 바로가기를 **핵심 6개 카드**로 교체. 일본크루즈, 크루즈 기항지, 도쿄 여행, 일본 여행지, 즐길거리, 여행 정보.
- 사이트 전체 1,271 HTML 중 **콘텐츠 페이지 1,269개**에서 새 헤더 사용; `/route/`, `/routes/`의 이동 안내 2개는 제외.
- 대표 페이지: 홈페이지, 일본 여행지, 도쿄 220편, 기항지 145편, 동행 가이드, 예약 안내.
- 기존 게시글 본문, 페이지 제목, canonical, OG, Article JSON-LD는 건드리지 않도록 `build.js`의 헤더 부분만 교체한다. 
- 핵심 구현: `scripts/v301-v305-nav.cjs` (정적 사이트 빌드), `site/v301-nav.css`, `site/v301-nav.js`.
- 시각 검사: 320/390/768/1024/1200/1440px, PC와 모바일 클릭·키보드·현재위치, 내부 메뉴 링크와 기존 페이지 메타데이터.
- 자동 감사: `audit-reports/v301-v305/browser-qa.json`, `audit-reports/v301-v305/live-production.json`.
