# V92 — 예약 동선 중복 제거 및 실제 클릭 흐름 최종 QA

**2026-10-21 기준. 기존 게시글 유지, 신규 콘텐츠 0편.**

## 변경 목표

방문자가 **항로 선택 → 공식 선사 사이트 이동**까지 혼란 없이 진행하도록 기존 페이지의 중복 버튼을 제거했다. 단, "1클릭"은 **NIPPONFERRY에서 선사 소유 사이트로 이동하는 1회 클릭**을 의미하며 **발권·잔여좌석·예약 완료를 뜻하지 않는다.**

### 기존 6개 페이지만 수정

- `site/ferry/index.html`
- `site/booking/japan-cruise/index.html`
- `site/guide/busan-osaka-ferry/index.html`
- `site/guide/busan-fukuoka-ferry/index.html`
- `site/guide/busan-shimonoseki-ferry/index.html`
- `site/guide/busan-tsushima-ferry/index.html`

공통 스타일: `site/nf-v92-booking-ux.css`. **기존 URL, canonical, 페이지 제목, V87 운영정보, V88·V90 공식 공지/링크 감시, V91 항로별 3항목 체크리스트 유지.** 신규로 검색엔진에 노출되는 개별 콘텐츠 URL 없음.

## 공식 선사로 이동하는 4개 항로

| 항로 | 1클릭 도착점 | 주의사항 |
|---|---|---|
| 오사카 | https://www.panstarcruise.com/ | 선사 홈페이지에서 오사카 항로·날짜 선택 |
| 후쿠오카 | https://www.koreaferry.co.kr/rs/idv/reservation/calendar_index/1/2?country=2 | 뉴카멜리아 한국어 날짜·인원 검색 화면 |
| 시모노세키 | https://www.kampuferry.co.jp/lang_kor/reserve/ | **한국어 예약방법 안내 화면**, 결제 완료 아님 |
| 대마도 | https://www.panstarcruise.com/ | 대마도·히타카츠/이즈하라 및 날짜 선택 |

각 항로 카드의 두 번째 내부 링크는 `/guide/busan-{route}-ferry/#nf87-verified-operations`로 이동해 확인일이 명시된 운항시간·요금 출처를 보여준다. 기존 가이드에서 `#nf86-official-entry`, `#ferry`, `#nf87-verified-operations` 앵커는 모두 유지된다.

기존 V90 공식 예약 링크 감시가 해당 4개 선사 도착지를 계속 점검한다. 리디렉션·404·잘못된 항로/도메인은 담당자 검토 이슈로 올리고, 403/봇 차단을 잘못된 URL로 단정하거나 금액·운항·링크를 검증 없이 자동 게시하지 않는다.

## 실제 공개사이트 QA

- 최종용 Playwright: `scripts/v92_booking_path_browser_qa.py`, 워크플로: `.github/workflows/v92-booking-path-qa.yml`.
- PC 1440×900, 모바일 390×844, 소형 360×780: **6개 기존 페이지 × 3가지 화면 = 18개 페이지/뷰포트 조합**.
- 실제 사람과 같은 새 탭 클릭으로 **2개 허브 × 4개 항로 × PC/390px = 공식 선사 도메인 접속 16회**.
- **2개 허브 × 4개 항로 = 8회** 실제 내부 링크로 V87 공식 운항·요금 영역 이동.
- 각 기사 내 외부 버튼 수 3개, 각 허브 카드의 외부 버튼 1개, 동일 4항로 중복 링크의 부재, 모바일 44px 이상 터치 영역, Kakao 고정 버튼과 겹침, 가로 화면 넘침, 앵커와 canonical 보존 검증.
- 증거: 30장 실제 페이지 캡처(항로 상단·하단 24장 + 허브 6장), JSON 결과 및 이동 최종 주소.
- **정상 통과한 첫 검사:** https://github.com/mouk30/japan/actions/runs/39574991383 (18/18 화면, 공식 사이트 클릭 16/16, 사실정보 링크 8/8).
- 최종 문구 정리 후 회귀 검사: https://github.com/mouk30/japan/actions/workflows/v92-booking-path-qa.yml
- 기존 V86, V90, V91 검사 스크립트와 자동 링크 감시의 로컬 검사도 변경한 **간결한 버튼 구조**를 이해하도록 업데이트했다.

## 검증 범위 한계

실제 방문자의 클릭률 또는 매출·예약전환 상승을 측정한 데이터는 없음. QA가 증명하는 것은 **실제 브라우저에서 올바른 외부 선사 도메인으로 클릭 이동 가능**, 구 버전 중복 버튼 제거, 디바이스별 누름 영역·표시 정상 여부다. 특정 운항일의 실제 좌석·요금·결제 성공 또는 판매가 보장됐다는 의미가 아니다.
