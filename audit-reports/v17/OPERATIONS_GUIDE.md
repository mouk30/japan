# NIPPONFERRY V17 — 실제 항차 운영정보 유지관리 기준

최초 점검: 2026-10-14. 사용자에게 공개하는 수치는 해당 시점의 **공식 안벽예약·입출항 예정정보**일 뿐 실시간 보장이 아닙니다.

## 현재 근거 수준
- 15개 항만 / 기존 동행 가이드 45편. 신규 공개 페이지 0개.
- 공식 선박명+예정 접안 선석+입출항 시각이 확인된 곳: **5항만·18항차** (요코하마/나가사키/하카타/하코다테/아오모리).
- 나머지 10개 항만: 선박명·날짜가 연결된 일정표를 이번 갱신에서 확인하지 못함.
- 항차별 **실제 승객 출입 게이트 번호, 셔틀 막차, 시설 정문까지 실측시간**: 확인된 것으로 간주하지 않음.
- 공식 일정은 취소/시간·선석 변경 가능. 출항예정시각은 **최종 승객 귀선 마감**과 다름.

## 데이터 갱신 절차
1. `scripts/v17-official-sailings.json`에서 해당 항만의 공식 일정표 링크에 접속.
2. 날짜, 선박명, 입·출항 예정시각, 실제 *안벽 명칭*, 공표/변경일, 취소 여부를 원문과 대조.
3. 확정되지 않은 셔틀/보안 게이트/차량 진입은 출입허용·교통안내 자료와 구분해 `미확인` 유지.
4. 일정 변경이 있으면 기존 일정 행을 교체하거나 취소 표시; 항차 이력을 예고 없이 정확한 운영으로 주장하지 않음.
5. 기준일 갱신, `scripts/v17-ops-apply.py` 실행 → 기존 45편에만 반영.
6. 브라우저 검수 `scripts/audit-v17-ops-live.mjs`에서 180회 화면·본문·공식링크 비교.
7. 특히 하선 당일에는 **선사·현지 항만 관리자 통보가 공공 예정표보다 우선**.

## 수치의 의미
- `입항 예정`: 선박이 항만에 도착할 것으로 게시한 시간.
- `출항 예정`: 선박이 항만에서 출발할 것으로 게시한 시간.
- `최종 귀선시간`: 선사가 승객별 안내하는 시간; 항만 홈페이지에 없으면 반드시 미확인.
- `셔틀/막차`: 선사·관광업체별 운영정보; 일반 노선버스/쇼핑몰 셔틀과 구별.
- `승객 게이트→시설 현관`: 실제 정문·보안 구역을 반영한 단일 통과 구간; 일반 지도 예상시간을 실측으로 표기 금지.

## 다음 우선 순위
1. 일정표가 공식 공개된 **미검증 10항만**의 항차별 날짜·접안 선석을 우선 추가.
2. 공개 일정과 무관하게 **관광객 셔틀의 당일 운행·마지막 복귀**를 선사/운송사에 확인.
3. 관광시설 앞 차량 하차 허용 지점·보행접근·휠체어 조건 등 현장 실무 자료 확보.
4. 확인된 정보만 페이지 반영, 검증 근거/날짜 유지.
5. 색인·검색 성과와 이용자 체감 품질은 별도의 관찰 지표로 관리.

공식 일정이 없는 항만을 '운항하지 않음'으로 표기하지 않도록 주의하십시오. 미검증은 결항 또는 미기항이 아닙니다.
