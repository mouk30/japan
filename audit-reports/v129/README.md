**V129 다음 제안:** 신규 글을 추가하지 않고 실제 촬영 장소·사진 출처·본문 일치, 오래된 촬영 사진, 게시물 링크·공식 예약·하선·귀선 정보의 최신성을 전역 점검할 것.
