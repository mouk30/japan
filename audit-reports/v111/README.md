**작업일: 2026-10-22 | NIPPONFERRY | 신규 게시글 0편 | 기존 10편 수정**

## 수정 요약

- 기존 크루즈 기항지 **10편 전부** 대표 사진의 출처(원본 링크, 촬영자, 라이선스), 사진과 장소의 일치, 현재 부두와 관광지 사진의 차이를 재확인했다.
- **대표 사진 4개 교체:** 사세보(우미키라라 수족관 → 하우스텐보스 돔토른 전경), 가나자와(관광물산관 → 히가시차야 전통거리), 미야코지마 히라라(리조트 → 요나하 마에하마 해변), 고베(어린이박물관 → 메리켄파크 포트타워 야경).
- **OG 이미지 7곳 수정:** 아오모리·사세보·가나자와·시미즈·미야코지마·가고시마·고베에서 기존 연출/다른 이미지 대신 실제 대표 사진과 OG 썸네일을 일치시켰다.
- **과거 잘못된 설명 2곳 제거:** 고치와 마쓰야마의 실제 사진 옆에 남아 있던 ‘공통 크루즈 참고 이미지/현지 실사가 아님’이라는 오래된 문구 삭제.
- **구마모토 역사사진 구분:** 구마모토성은 **2016년 구마모토 지진 이전인 2005년 자료 사진**이라고 명시했다.
- 현재 이미지의 폭·높이 속성을 실제 WebP 크기에 맞추고, 10편의 눈에 보이는 사진 설명과 원본·저작자·라이선스 링크를 표준화했다.

## 보존한 SEO/본문 구조

- 원본 URL, HTML `title`, 메타 설명, `canonical`, H1, `Article/FAQ/Breadcrumb JSON-LD`와 내부 여행 안내를 기존 그대로 유지한다.
- [기존 SEO 필드 잠금 스냅샷](./seo-baselines.json)을 사진 변경 전에 생성하여 코드 검수에서 문자 단위로 비교한다.
- 기존 사이트 내 확인된 WebP만 재사용하고, 라이선스 확인 없이 이미지를 외부에서 새로 가져오거나 자동 생성하지 않는다.
- 관광지 사진은 크루즈의 실제 접안 부두·승객 하선 게이트·셔틀 운영·현재 개장 정보의 증거가 아니다.
