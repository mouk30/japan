## 실사진과 현재 운영정보의 구별

사진은 실제 지역·관광명소에서 촬영되었지만 모든 사진이 **현행 크루즈 접안 부두·하선 게이트·셔틀 동선**을 증빙하는 것은 아닙니다.
특히 고즈시마 마을과 산, 미스미 서항, 도요하시역, 나카구스쿠성터, 나카쓰성, 다카다 성터공원은 각 지역의 관광명소이며 현대 크루즈 하선시설과 구별해 명시했습니다.
**2007년 촬영한 나나오항**은 2024년 노토반도 지진 이후의 상태를 보증하지 않습니다. **2008년 촬영한 미야케지마 미이케항** 또한 촬영 당시의 기록이며 현재 운영현황이 아닙니다.
