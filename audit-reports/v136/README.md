## 판정
대표사진 경로, alt, 사진 출처표기 유무는 확인했다. 기존 jpg 이미지 픽셀 자체의 원본 역추적과 Commons 원본·저자·라이선스 독립대조는 미완료다. 따라서 여섯 사진이 실제로 다른 장소를 묘사한다고 **확정하지 않았다**. 검증하지 않은 사진으로 임의 교체하는 대신 기존 운영 페이지를 유지한다. 249편은 여전히 '검토 후보'이며 이번 조사로 6편의 출처 부재를 확인했어도 원본 장소·라이선스가 확인된 완료 건수로 차감하지 않는다.

## 이후 안전한 변경 조건
1. 교체 후보 원본에 *촬영 장소, 촬영일, 저작자, 상업적 사용 가능한 라이선스 및 의무적 출처 표기*가 확인되어야 한다.
2. 원본 설명과 사진 피사체가 페이지 주제에 맞아야 한다. 페리 안내는 일반 항구 사진을 특정 국제선 승선 게이트로 단정하지 않는다.
3. 교체 시 기존 title / meta description / canonical, 예약 및 귀선 안내를 그대로 보존한다. 대표 이미지와 og:image, twitter:image를 동일한 검증 WebP로 연동한다.
4. 배포 후 공개 주소에서 사진 응답, 사진 크레디트, 본문 일치, PC·모바일을 별도 검증한다.
