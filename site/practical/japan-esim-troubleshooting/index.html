1. 실제 개통 시점

2. 데이터 회선·로밍

03

3. 신호·APN·재부팅

수신 음영지역을 벗어나고 자동 네트워크 선택·APN 설정을 확인한 후 재부팅합니다.

04

4. 삭제보다 고객센터

문제 화면을 캡처하고 주문번호와 단말기 모델을 준비해 판매처에 문의하세요. eSIM 삭제는 재사용·재발급 조건 확인 후 결정하세요.
