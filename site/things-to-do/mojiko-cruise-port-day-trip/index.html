기타큐슈·모지항 크루즈 기항지｜접안 부두·당일 관광·교통·귀선 가이드

역사적인 벽돌 건물과 해협 풍경이 만나는 항구 산책. 기항지 관광을 즐기려면 먼저 접안 부두와 최종 귀선 시간을 확인해야 합니다.

기항지 출발 전 4단계 확인표

공식 항만·관광 정보와 해당 항차의 미확인 사항을 분리했습니다. 아래 항목의 ‘미확인’은 운행하지 않는다는 뜻이 아닙니다.

  1. ① 하선 게이트모지 서해안·고쿠라·히비키 선석 후보
  2. ② 현지 교통하선 선석별 셔틀·보안 출입구 확인 필요
  3. ③ 관광지 입구모지코역·레트로 관광권 확인, 항만 게이트 별개
  4. ④ 귀선 안전항차별 보안 게이트·귀선 마감 미확인

출항시각 ≠ 승객 최종 귀선 마감 — 선사 공지와 승선카드를 우선하고, 귀선 차량을 사전에 확보하세요.

실제 하선 게이트부터 관광지까지 · 공식 정보 점검

출발점: 기타큐슈시는 크루즈 접안 후보를 모지 서해안 1·2호, 6호, 고쿠라 아사노 1호, 히비키 컨테이너터미널 등으로 구분합니다. '모지항'이라는 표기만으로 모지코 레트로 도보 관광을 가정하면 안 됩니다.

게이트·현지 교통

모지 서해안 1·2호 선석은 모지코 레트로 관광권과 가까운 곳이지만 6호 및 고쿠라·히비키 터미널은 도보 동선이 다릅니다. 항차별 승객 게이트와 보안구역 출구, 차량 대기장 및 셔틀 유무를 반드시 확인하세요.

관광지 입구·승차장 확인

도착 권역: 모지코역·레트로 거리 보행권. 모지코역의 일반 관광 출입구와 크루즈 승객 전용 항만 보안 게이트를 혼동하지 마세요. 지정된 항만 출입구로만 귀선해야 합니다.

입구·운영정보 검증 상태: 관광 권역은 식별했으나 방문일의 정확한 시설 입구·교통 승하차 지점은 항차별 확인 필요. 확인되지 않은 도보 분수·차량 출발시간·셔틀 막차를 확정값으로 제공하지 않습니다.

당일 관광 동선 — 확정 시간표가 아닌 계획 예시

모지 서해안 1·2호 접안과 출입 허용 동선이 확인된 경우 → 모지코 레트로·모지코역을 중심으로 한 곳 또는 두 곳 관광 → 항만 지정 출입구로 복귀. 다른 선석이면 관광 출발 전에 공식 교통편을 먼저 확정합니다.

승객 귀선 안전 확인

기타큐슈시 2026년 9월 갱신 자료에서도 접안 선석은 여러 곳입니다. 예전 항차에 제공된 셔틀이나 도보 동선을 오늘의 선박에 적용하면 안 됩니다.

선박 출항시간과 승객 최종 귀선 마감은 다릅니다. 선사 앱·선내 안내에서 선박명, 항차, 부두, 귀선 게이트, 지정 귀선 시각을 반드시 확인하세요.

공식·기관 자료 확인 링크: 기타큐슈시 크루즈 입항·선석 공식 안내

정보 검토일: 2026-10-14. 링크가 제공되어도 해당 항차 셔틀 운행·시설 예약 가능·귀선 시각이 확정된 것은 아닙니다.

1. 기타큐슈·모지항 크루즈 접안 부두·하선 준비

항구명만으로 터미널이나 하선 출입구를 단정할 수 없습니다. 같은 지역에서도 선박 크기와 일정에 따라 접안 부두가 달라집니다. 승선 전 선사 앱·일정표에서 부두 이름, 셔틀 정류장, 임시 출입구, 출입국 절차, 승객 최종 귀선 시간을 확인하세요.

모지코역 일대에 접근 가능한지 크루즈 실제 접안지와 셔틀 동선을 확인. 크루즈 전용 셔틀이 제공되는 경우 출발·막차 시각과 운행 구간을 함께 확인해야 합니다.

2. 하선 후 가볼 만한 곳

모지코 레트로

모지코 레트로은 기타큐슈·모지항 관광 계획에서 우선 고려할 만한 명소입니다. 관광 시간을 짧게 쓸 경우 이 장소 한 곳에 집중해 주변 산책과 식사 여유를 확보하세요. 현장 운영 시간과 이동 수단은 당일 기준으로 다시 확인해야 합니다.

간몬해협 전망

간몬해협 전망은 시간이 더 넉넉할 때 추가할 수 있는 관광 대안입니다. 이동 거리가 긴 경우 무리하게 묶지 말고 먼저 왕복 교통과 마지막 입장 시각을 점검하세요.

3. 반나절 관광 추천 동선

짧은 기항 · 여유 있는 한 곳 여행

접안 부두 및 하선 → 모지코 레트로 → 항구 복귀 → 승객 귀선

긴 기항 · 선택형 확장

하선 → 모지코 레트로 → 이동시간 확인 후 간몬해협 전망 또는 지역 식사 → 항구 복귀

제시한 일정은 관광 동선의 예시이며, 특정 크루즈의 실제 기항 시간표는 아닙니다. 셔틀 대기, 출입국 수속, 교통 혼잡과 선사 귀선 마감 시각에 맞게 조정하세요.

4. 현지 교통과 귀선 체크

모지코역 일대에 접근 가능한지 크루즈 실제 접안지와 셔틀 동선을 확인. 항구에서 목적지까지 대중교통 연결이 불편할 경우 항만 지정 택시 승강장, 공식 셔틀 또는 사전 예약 차량을 검토하세요.

최종 귀선 전 필수 확인

① 실제 접안 부두와 재승선 출입구 ② 돌아오는 셔틀·차량편 ③ 선사가 공지한 최종 승객 귀선 시각 ④ 교통 지연을 고려한 여유 시간. 관광시설의 정상 운영과 현지 교통편은 여행일 공식 안내를 우선합니다.

5. 자주 묻는 질문

기타큐슈·모지항 기항 시 하선 후 바로 도보 관광이 가능한가요?

선박별 배정 부두·터미널 출입구와 셔틀 제공 여부에 따라 달라집니다. 항차별 하선 안내를 먼저 확인하세요.

기타큐슈·모지항의 당일 관광 추천 코스는 무엇인가요?

짧은 기항에는 모지코 레트로 중심으로 일정을 구성하고, 시간이 충분하면 간몬해협 전망 방문을 검토하세요.

귀선 시간은 출항 시각과 같나요?

다릅니다. 선사 안내문의 승객 최종 귀선 마감 시각을 우선 지켜야 합니다.
