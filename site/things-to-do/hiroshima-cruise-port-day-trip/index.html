출발점: 접안 부두가 우지나 외무부두(크루즈터미널)인지 이쓰카이치 부두인지 먼저 확인하세요. 두 곳은 승객 동선과 시내 진입 방식이 다릅니다.

게이트·현지 교통

우지나 외무부두 제5선석은 히로시마항 크루즈터미널에 인접합니다. 히로시마 항만 운영기관은 이 부두의 택시가 선석 내부에 들어가지 않고 크루즈터미널 택시풀을 이용하도록 안내합니다. 이쓰카이치 부두는 항만 통제구역에 일반 차량 접근 제한이 있으므로 항차별 공식 셔틀·차량 승차장을 확인해야 합니다.

관광지 입구·승차장 확인

도착 권역: 평화기념공원·원폭돔 권역. 원폭돔 방문은 공원 외부 관람과 기념자료관 유료·입장 시설을 구분하세요. 자료관을 이용하려면 당일 공식 입장 및 입구 안내를 확인하세요.

입구·운영정보 검증 상태: 관광 권역은 식별했으나 방문일의 정확한 시설 입구·교통 승하차 지점은 항차별 확인 필요. 확인되지 않은 도보 분수·차량 출발시간·셔틀 막차를 확정값으로 제공하지 않습니다.

당일 관광 동선 — 확정 시간표가 아닌 계획 예시

우지나 하선 확인 → 터미널의 공식 탑승지점 → 히로시마항 전차·공식 셔틀 연결 확인 → 원폭돔·평화기념공원 중 가까운 권역에 집중 → 역순 복귀. 이쓰카이치 하선 시 이 동선을 그대로 적용하지 말고 항만 지정 환승 위치부터 다시 결정하세요.

승객 귀선 안전 확인

이쓰카이치 부두를 우지나로 혼동하면 복귀에 실패할 수 있습니다. 선사 최종 승객 귀선 마감(출항 시간과 다름)과 게이트, 셔틀 막차는 각 항차별로 확인해야 합니다.

선박 출항시간과 승객 최종 귀선 마감은 다릅니다. 선사 앱·선내 안내에서 선박명, 항차, 부두, 귀선 게이트, 지정 귀선 시각을 반드시 확인하세요.

1. 히로시마항 크루즈 접안 부두·하선 준비

항구명만으로 터미널이나 하선 출입구를 단정할 수 없습니다. 같은 지역에서도 선박 크기와 일정에 따라 접안 부두가 달라집니다. 승선 전 선사 앱·일정표에서 부두 이름, 셔틀 정류장, 임시 출입구, 출입국 절차, 승객 최종 귀선 시간을 확인하세요.

평화공원과 미야지마는 이동 동선이 달라 짧은 기항에는 한 곳을 선택. 크루즈 전용 셔틀이 제공되는 경우 출발·막차 시각과 운행 구간을 함께 확인해야 합니다.

2. 하선 후 가볼 만한 곳

평화기념공원

평화기념공원은 히로시마항 관광 계획에서 우선 고려할 만한 명소입니다. 관광 시간을 짧게 쓸 경우 이 장소 한 곳에 집중해 주변 산책과 식사 여유를 확보하세요. 현장 운영 시간과 이동 수단은 당일 기준으로 다시 확인해야 합니다.

미야지마

미야지마은 시간이 더 넉넉할 때 추가할 수 있는 관광 대안입니다. 이동 거리가 긴 경우 무리하게 묶지 말고 먼저 왕복 교통과 마지막 입장 시각을 점검하세요.

제시한 일정은 관광 동선의 예시이며, 특정 크루즈의 실제 기항 시간표는 아닙니다. 셔틀 대기, 출입국 수속, 교통 혼잡과 선사 귀선 마감 시각에 맞게 조정하세요.

4. 현지 교통과 귀선 체크

평화공원과 미야지마는 이동 동선이 달라 짧은 기항에는 한 곳을 선택. 항구에서 목적지까지 대중교통 연결이 불편할 경우 항만 지정 택시 승강장, 공식 셔틀 또는 사전 예약 차량을 검토하세요.

최종 귀선 전 필수 확인

① 실제 접안 부두와 재승선 출입구 ② 돌아오는 셔틀·차량편 ③ 선사가 공지한 최종 승객 귀선 시각 ④ 교통 지연을 고려한 여유 시간. 관광시설의 정상 운영과 현지 교통편은 여행일 공식 안내를 우선합니다.

5. 자주 묻는 질문

히로시마항 기항 시 하선 후 바로 도보 관광이 가능한가요?

선박별 배정 부두·터미널 출입구와 셔틀 제공 여부에 따라 달라집니다. 항차별 하선 안내를 먼저 확인하세요.

히로시마항의 당일 관광 추천 코스는 무엇인가요?

짧은 기항에는 평화기념공원 중심으로 일정을 구성하고, 시간이 충분하면 미야지마 방문을 검토하세요.

귀선 시간은 출항 시각과 같나요?

다릅니다. 선사 안내문의 승객 최종 귀선 마감 시각을 우선 지켜야 합니다.
