데시마 미술관 예약·이에우라/가라토항 귀선 가이드

데시마는 배가 도착하는 이에우라·가라토항과 미술관 위치가 다릅니다. 선사·승선항·미술관 시간지정권과 적은 버스편을 한 일정표에 맞춰야 안전하게 귀선할 수 있습니다.

먼저 돌아올 배편부터 선택하세요

섬으로 들어가는 배, 미술관 예약, 섬 내부 이동, 돌아가는 배는 각각 별개입니다. 특정 편의 실시간 운항·잔여 좌석·귀선 마감은 보장하지 않습니다. 크루즈 기항객은 대형 크루즈의 별도 최종 승선시간이 우선입니다.

이에우라·가라토는 서로 다른 항구

우노·쇼도시마를 잇는 배편 중에는 이에우라(家浦)와 가라토(唐櫃)를 경유하는 편이 있습니다. 모든 배가 두 항구에 정차하는 것은 아니므로 선편별 기항지를 확인하세요.

선사마다 운항 패턴 다름

우노·쇼도시마 방면은 쇼도시마 데시마 페리, 다카마쓰·나오시마 혼무라 방면은 데시마 페리, 미야노우라·데시마·이누지마는 시코쿠 기선 항로를 각각 확인합니다.

ARRIVAL → ART → RETURN

우노항 → 이에우라항 → 미술관 → 같은 목적지로 복귀

아래는 우노항 출발·복귀를 가정한 보수적인 예시입니다. 다카마쓰 또는 나오시마로 돌아갈 경우 선사·정박항이 달라지므로 그대로 적용하면 안 됩니다.

  1. 01

    우노항 출발편의 정박항 확인

    쇼도시마 데시마 페리 공식 시간표에서 우노→이에우라 또는 가라토 도착편을 고릅니다. 배 종류(페리·여객선)와 요일별 예외를 체크합니다.

  2. 02

    이에우라항 하선 후 버스 시간 확인

    이에우라항에서 데시마미술관 인근으로 가는 섬버스 출발편을 찾습니다. 버스 정원이 제한되어 서둘러도 탑승을 보장할 수 없습니다.

  3. 03

    데시마미술관 관람 예약과 이동 연결

    공식 운영 페이지에서 날짜·입장 시간을 선택합니다. 10~2월 오후 운영시간이 짧고 매주 화요일 등 휴관 규칙이 있으므로 미술관 캘린더 확인이 먼저입니다.

  4. 04

    관람 후 목표 귀선항으로 이동

    우노항으로 되돌아갈지, 다카마쓰나 나오시마로 갈지 결정한 뒤 해당 출항항(이에우라 또는 가라토)까지의 버스·도보시간을 계산합니다.

  5. 05

    귀선편 앞선 시간에 항구 대기

    섬버스를 한 대 놓쳐도 복귀 가능한지 확인하고, 기상으로 출항이 취소될 수 있음을 고려하세요. 데시마에서 나오시마로 이동한다면 미야노우라와 혼무라 도착항도 분리해 보세요.

RESERVATIONS & ACCESS

예약·운항에서 헷갈리기 쉬운 점

우노 ↔ 데시마쇼도시마 데시마 페리의 정기 시간표를 확인합니다. 공식 시간표는 2025년 12월 개정 기준이며 월 첫째 화요일의 일부 위험물 전용 운항은 일반 승객이 이용할 수 없습니다.
다카마쓰 ↔ 데시마데시마 페리는 3월 20일~11월 30일과 12월 1일~3월 19일, 요일별 시간표를 따로 안내합니다. 나오시마 혼무라 경유 여부도 다릅니다.
미술관 휴관일반적으로 3~11월 화요일 휴관, 12~2월 화~목요일 휴관(공휴일·대체휴관 예외). 예약 전 해당 일자 공식 달력을 확인하세요.
데시마미술관 입장권방문 날짜·시간 지정 사전 예약이 필요하며 온라인 매진이면 당일 현장 판매도 없습니다. 미술관 티켓은 여객선 좌석을 보장하지 않습니다.
섬버스 운임베네세 안내 기준 성인 400엔·어린이(5~12세) 200엔. 최신 운행시간은 섬 관광안내의 공식 버스 시간표가 우선입니다.

표는 2026-10-23에 열람한 공식 운영 안내의 핵심만 요약했습니다. 변경 가능한 운항시각과 예약 재고는 고정 표시하지 않았습니다.

귀선 실패를 피하는 시간 역산

우노항으로 돌아갈 때는 쇼도시마 데시마 페리의 '이에우라 또는 가라토 → 우노' 항차가 실제로 해당 항구를 경유하는지 먼저 확인합니다. 다카마쓰행과 나오시마행은 다른 운항사의 별도 편입니다.

주의: 이에우라항과 가라토항을 헷갈리면 귀선편에 탑승하지 못할 수 있습니다.

데시마미술관 입장 시간이 늦으면 섬버스 막차와 배 출항이 충돌할 수 있습니다. 섬 안의 교통편이 적으므로 '미술관 관람 포기 → 항구 바로 복귀' 대안을 미리 정해 두세요.

선사 공식 시간표에서 돌아갈 항구·날짜·배 종류·항차를 먼저 선택 → 해당 항구에 도착할 목표시각 설정 → 역방향 버스·도보 이동을 확인 → 미술관 관람 가능 시간을 결정하세요. 가능하면 마지막 배가 아닌 그보다 앞선 편을 목표로 여유를 확보하세요.

자주 묻는 질문

데시마에는 항구가 하나인가요?

아닙니다. 주요 정기선 이용 항구인 이에우라항과 가라토항은 서로 다릅니다. 이용할 배편이 정차하는 항구를 정확히 확인해야 합니다.

데시마미술관 당일 입장권을 현장에서 살 수 있나요?

공식 안내는 방문 날짜·시간 지정 사전 예약을 요구하며 온라인 판매가 매진되면 해당 날짜 현장 판매도 없다고 설명합니다. 사전에 온라인 예약 상태를 확인하세요.

데시마에서 나오시마로 바로 갈 수 있나요?

해당 운항일의 시코쿠 기선 미야노우라 연계편이나 데시마 페리의 혼무라 경유편을 확인해야 합니다. 나오시마의 미야노우라항과 혼무라항은 서로 다른 곳입니다.
